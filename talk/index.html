The code gets out of the way, you focus on the study

using WaterLily, WaterLilyMeshBodies, BiotSavartBCs

# Import the animal: any STL, from a scan or CAD
body = MeshBody("dolphin.stl"; map=swim)

# Add the motion: a wave running down the body
swim(x,t) = x - x₀ - [0, 0, a(x[2])*sin(k*x[2] - ω*t)]

# Swim it in a box that hugs the body
sim = BiotSimulation(dims, (0,U,0), L; body, ν=U*L/Re)
sim_step!(sim, 10)

A free swimmer's speed depends on the flow, so walls matter. Ordinary walls reflect the wake: the ring breaks up. [click] Biot–Savart walls act like open water. Evan's box: 3 × 2 × 2 diameters; doubling it changes the force 4%.
